# 🎧 Auralis — Documentación

Panel de audio estilo Dolby Access, hecho con **Tauri + React + Rust**, que controla
**Equalizer APO** para procesar TODO el audio del sistema Windows.

## 🧠 Cómo funciona
Auralis (UI) ──invoke()──> Rust (commands.rs) ──escribe──> config.txt │ Equalizer APO recarga ──> procesa ──> drivers de audio ──> bocinas/auriculares

La app no procesa audio directamente: genera la configuración de Equalizer APO.
Cada cambio de UI (modo, slider, toggle) escribe C:\Program Files\EqualizerAPO\config\config.txt.
EQ APO detecta el cambio y aplica al instante.

🔌 Conectar un NUEVO dispositivo de audio (BT, USB, monitor...)
Cada dispositivo tiene un ID propio en Windows — hay que registrar el APO para cada uno:

1. Conectar el dispositivo nuevo
Conecta los auriculares BT / USB ANTES de continuar

### 2. Verificar que Windows lo ve
```powershell
Get-PnpDevice -Class AudioEndpoint -Status OK | Select-Object FriendlyName
→ debe aparecer el nuevo (ej. "Auriculares (Steren POD-177)")

3. Abrir el selector de dispositivos de EQ APO
Desde el Explorador (NO desde terminal): doble click en
C:\Program Files\EqualizerAPO\DeviceSelector.exe
(click derecho → Ejecutar como administrador)
⚠️ Si se lanza desde otra carpeta da el error "no Qt platform plugin". El doble click desde su carpeta siempre funciona.

4. Marcar los dispositivos
Dispositivo	Marcar
El nuevo (ej. "Auriculares (Steren POD-177)")	✅ SÍ
Realtek HD Audio 2nd output / Altavoces	✅ mantener
Variantes "con micrófono" / "Hands-Free"	❌ NO (modo llamadas)
Salidas NVIDIA (monitores)	❌ NO
Micrófonos / capture	❌ NO
5. Aplicar y reiniciar
OK → reiniciar el PC
6. Probar
Abrir Auralis (admin) → modo Voice → ON/OFF → el sonido debe cambiar
Si no aplica tras reconectar BT
Restart-Service Audiosrv -Force
🔧 Solución de problemas
Problema	Fix
"Equalizer APO no encontrado"	Instalar EQ APO (requisito)
"No se pudo escribir la config"	Ejecutar Auralis como administrador
BT no procesa	El dispositivo no está registrado → sección "Conectar nuevo dispositivo"
Leveler no hace nada	Verificar TDR Nova.dll en la ruta VST2 + nova_vst.txt con chunk
EQ APO Editor abierto pelea con Auralis	Cerrar Editor.exe antes de usar Auralis
